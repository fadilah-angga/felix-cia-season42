Cara pasang:
1. music.mp3  -> taruh file lagu "Pelangi - HIVI!" di folder ini, namanya persis music.mp3
2. stiker/1.jpg .. 4.jpg -> udah diisi, ganti aja kalau mau
3. Foto ada di img/ — ganti/tambah sesuka hati (edit <figure class="polaroid"> di index.html)
4. Deploy: drag folder ini ke vercel.com/new atau `vercel --prod`
5. pajangan/1.png .. 3.png -> gambar buat bingkai emas di "Pojok Pajangan" (PNG transparan paling bagus). Kalau kosong, otomatis tampil bintang laut pink.
